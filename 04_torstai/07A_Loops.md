Objectives
Create a program using loops, if statements and calculations

description.pngDescription
Kangaroo Zoo Calculator

Kangaroo Zoo is a fun place for kids to play here in Utah.  Write a program to help parents calculate the cost of attending for their entire family based on the following prices.

3 and under Active all day play                       $ 6.00
Adults                                                                $ 12.00
Frequent Flopper Pass - 10 admissions         $ 85.00
3 and under Flopper Pass - 10 admissions    $ 50.00

Create a main menu with options to calculate cost or to quit the program.  After the user has selected their option, the program will repeat the main menu to allow the user to calculate different costs.
